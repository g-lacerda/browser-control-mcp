Primeira vez

Como ligar ao Claude Code

  1. Compile o servidor local Na pasta do projeto: npm install && npm run build. Ele roda só no seu computador.
  2. Registre no Claude Code Troque o caminho pelo da pasta onde você clonou o projeto e rode no terminal:
    Carregando…
  3. Reinicie o Claude Code Saia e rode claude --continue. Pronto: peça pra ele abrir um site.

Autorização

Como o Claude pede licença

No modo autônomo ele age em qualquer site sem perguntar. No outro, você libera cada site na primeira vez.

Sites liberados

    Sempre ligado

    O que vale em qualquer modo

    • Só as abas do grupo "Claude". As suas não são lidas, listadas nem fotografadas.
    • Nada sai do seu computador pela extensão: o próprio Firefox só deixa ela falar com o servidor local.
    • Cartão só de teste (sandbox). Número de cartão de verdade é recusado.
    • O botão da extensão e o botão "Pausar o Claude" na página param tudo na hora.
    • Toda ação fica no registro aqui embaixo.

    O que o Claude pode fazer

    Sites bloqueados

    Um site por linha. O Claude nunca age neles, nem no modo autônomo. Subdomínios entram junto.
